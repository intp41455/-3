# 05 · 本地开发与部署

---

## 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| Node.js | ≥ 18（推荐 20 / 22 LTS） | Vite 6 的最低要求 |
| 包管理器 | npm / pnpm / yarn / bun 均可 | 仓库内有一份 `bun.lock`（AI Studio 环境产物），用 npm 安装不受影响 |
| 浏览器 | 任一现代浏览器 | 全屏、剪贴板、`requestFullscreen` 依赖现代 API |
| 网络 | 首次安装依赖需要；**运行时除 Google Slides 导出外无需联网** | Google Fonts 为可选增强 |

## 安装与运行

```bash
npm install
npm run dev
```

`dev` 固定监听 **3000** 端口并开放 `0.0.0.0`：

```json
"dev": "vite --port=3000 --host=0.0.0.0"
```

访问 http://localhost:3000

### 开箱即用的范围

| 功能 | 不登录能用吗 |
|---|---|
| 15 页宣贯演讲（含逐字稿） | ✅ |
| 10 维度 78 问问卷（查阅 / 检索 / 导出） | ✅ |
| 四阶段流程图（含 Mermaid 源码复制） | ✅ |
| 本地导出（问卷 MD / 讲稿 MD / 离线 HTML） | ✅ |
| **导出到 Google Slides** | ❌ 需登录 Google 账号 |

## 全部脚本

| 脚本 | 命令 | 用途 |
|---|---|---|
| `dev` | `vite --port=3000 --host=0.0.0.0` | 开发服务器 |
| `build` | `vite build` | 生产构建 → `dist/` |
| `preview` | `vite preview` | 预览构建产物 |
| `lint` | `tsc --noEmit` | **类型检查**（本项目唯一自动化校验） |
| `clean` | `rm -rf dist server.js` | 清理产物 |

> ⚠️ `clean` 里的 `server.js` 是 AI Studio 模板遗留，仓库中不存在该文件；`rm -rf` 在 Windows 的 cmd/PowerShell 下不可用。跨平台请换 `rimraf`。

## 环境变量

```bash
cp .env.example .env
```

| 变量 | 说明 | 当前是否需要 |
|---|---|---|
| `GEMINI_API_KEY` | Gemini API 密钥（AI Studio 运行时从用户 Secrets 自动注入） | **不需要**——源码中无任何模型调用 |
| `APP_URL` | 应用 URL（自引用链接 / OAuth 回调） | 可选 |

> `metadata.json` 声明了 `MAJOR_CAPABILITY_SERVER_SIDE_GEMINI_API`，但 `src/` 下**没有 `@google/genai` 的引用**。该能力当前未启用。

## Firebase / OAuth 配置

`firebase-applet-config.json` 由 AI Studio 生成。**若要在自己的 Firebase 项目下运行**，需要：

```text
1. 新建（或选用）Firebase 项目
2. 项目设置 → 常规 → 添加 Web 应用 → 拿到 firebaseConfig
3. 用新配置替换 firebase-applet-config.json
4. Google Cloud Console → API 和服务 → 库
   启用：Google Slides API、Google Drive API
5. 凭据 → OAuth 2.0 客户端 ID → 授权来源
   加入：http://localhost:3000、https://你的域名
6. 凭据 → API 密钥 → 应用限制
   加入 HTTP 来源限制（localhost:3000 与生产域名）
```

详细的安全建议见 [04-认证授权与安全说明.md](04-认证授权与安全说明.md)。

## 构建与部署

```bash
npm run build     # → dist/
npm run preview   # 本地验证
```

产物是**纯静态站点**，可部署到任何静态托管：

| 平台 | 配置 |
|---|---|
| Cloudflare Pages | 构建命令 `npm run build`，输出目录 `dist` |
| Vercel / Netlify | 框架预设选 Vite |
| GitHub Pages | `dist` 推 `gh-pages`；注意按仓库路径设置 `base` |
| 内网 Nginx | `dist` 丢根目录 |

### ⚠️ 部署后必须做的事

**OAuth 的授权来源白名单必须加入部署域名**，否则 Google 登录会直接报 `auth/unauthorized-domain`。

同时在 Firebase Console → Authentication → Settings → **Authorized domains** 里也要加上该域名（这是 Firebase 层的要求，与 Google Cloud 层的 Authorized origins 是两处独立配置，**都要改**）。

### 不需要服务端

应用是纯前端 SPA，没有 SSR / API 路由 / 数据库。唯一的外部交互是浏览器直连 Google 的 API。

## AI Studio 工作流

`vite.config.ts` 中的 AI Studio 专用逻辑：

```ts
server: {
  // HMR is disabled in AI Studio via DISABLE_HMR env var.
  // Do not modify—file watching is disabled to prevent flickering during agent edits.
  hmr: process.env.DISABLE_HMR !== 'true',
  watch: process.env.DISABLE_HMR === 'true' ? null : {},
}
```

AI Studio 内编辑代码时会把 `DISABLE_HMR` 置为 `true`。**本地开发不要设置该变量**。

导出代码：AI Studio 右上角菜单 → **Export** → **Download ZIP** 或 **Push to GitHub**。

## 开发注意事项

| 事项 | 说明 |
|---|---|
| **改动前跑 `npm run lint`** | 项目无测试，`tsc --noEmit` 是唯一静态保障 |
| **改流程要改两处** | `MermaidWorkflow.tsx` 的 `RAW_MERMAID` 与 `STEPS` 是两份独立数据，靠 `id` 隐式对应，无校验 |
| **新增页型要改三处** | `types.ts` 的 `layout` + `PresentationViewer` 渲染分支 + `slidesExport` 灌入逻辑 |
| **改页数要改文案** | `slidesExport.ts` 里写死了「正在批量构建 15 页幻灯片内容...」 |
| **Google Slides 导出要在真实账号上验证** | 「能跑通类型检查」不等于「能授权成功」，OAuth 作用域与 API 启用状态只能实测 |
| **不要依赖 `npm run clean`** | 见上文模板遗留说明 |
| **字体来自 Google Fonts CDN** | `index.html` 引入 Cormorant Garamond / Inter / Space Mono。内网离线会回退系统字体，版式略有差异 |
| **CJK 与 Emoji 在 Slides 端渲染不同** | 流程图数据里的 Emoji 在 Google Slides 中可能显示为不同字形 |
